# BusinessAI.SK

BusinessAI.SK — jednoduchý AI nástroj pre podnikateľov a živnostníkov na Slovensku.

## Cieľ MVP

Pomôcť používateľovi rýchlo:
- vytvoriť podnikateľský nápad a základný plán,
- odhadnúť náklady a cenu,
- pripraviť texty pre zákazníkov a sociálne siete,
- získať praktické AI odporúčania pre slovenské podnikateľské prostredie.

## Technológia

Prvá verzia používa čisté HTML, CSS a JavaScript bez build procesu, aby sa dala jednoducho upravovať aj z mobilu a publikovať cez GitHub Pages.
